# Cierre de producción: datos comerciales

Revisión del catálogo local: se encontraron 23 modelos y 100 variantes de color, y las rutas de imagen asociadas están presentes. Este chequeo confirma integridad de archivos, no inventario real ni correspondencia visual exacta entre foto, modelo y color.

Antes de aceptar pagos o anunciar disponibilidad, completar en el catálogo los datos confirmados por el negocio para cada combinación de modelo, capacidad y color:

- Precio de venta y moneda; indicar si el precio es al contado, incluye impuestos y cuándo vence.
- Unidades disponibles o estado de reserva. El código no contiene un inventario verificable para todos los modelos.
- Garantía real, quién la brinda, plazo, cobertura y exclusiones.
- Condiciones de reserva, pagos, cambios y devoluciones.
- Entrega en Lima y tarifas, plazos, cobertura, operador y seguimiento para provincias.
- Estado del equipo (nuevo, sellado u otra condición), accesorios incluidos y compatibilidad regional/SIM cuando corresponda.

Los iPhone 18 Pro y 18 Pro Max tienen el campo de precio sin completar. No publicar una compra con importes implícitos: el flujo actual dirige al cliente a confirmar por WhatsApp. Antes de abrir reservas, confirmar por escrito que el proveedor ofrece esas variantes, las fechas y las condiciones de la reserva. No asumir stock ni fecha de entrega.

El despliegue será manual en Hostinger. Antes de ejecutar el build local que subirás, crea `.env.local` con `NEXT_PUBLIC_SITE_URL=https://tu-dominio-real` para generar canonical y sitemap correctos. No uses la dirección de Sites. La página permite indexación; tras subirla, verifica dominio, sitemap y propiedad de Search Console.
